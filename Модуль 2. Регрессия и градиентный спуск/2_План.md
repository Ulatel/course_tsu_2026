# Модуль 2. Регрессия и градиентный спуск

**Семестр:** 1

## Образовательные результаты

### Знают
- основные показатели качества данных (точность, полнота, согласованность, своевременность);
- принцип работы и постановку задачи регрессии;
- понятия гиперпараметров и переобучения/недообучения.

### Умеют
- строить и валидировать регрессионные модели;
- реализовывать градиентный спуск для линейной регрессии «с нуля»;
- подбирать гиперпараметры;
- интерпретировать результаты обучения.

### Понимают
- оптимизацию функции потерь через градиентный спуск.

## Темы лекции. Постановка задачи регрессии, процесс обучения, минимизация ошибки через градиентный спуск

- Постановка задачи регрессии: непрерывная целевая переменная и её отличие от классификации.
- Процесс обучения модели: признаки → модель → предсказание → ошибка (loss).
- Минимизация ошибки: идея градиентного спуска (движение в сторону антиградиента).
- Качество данных как фундамент модели: точность, полнота, согласованность, своевременность.
- Переобучение и недообучение; роль гиперпараметров и регуляризации.
- Связь с проектом: прогнозирование стоимости домов на Kaggle (House Prices).

## Темы теории

### Тема 0. Качество данных

- Показатели качества данных: точность, полнота, согласованность, своевременность.
- Влияние качества данных на модель; принцип «мусор на входе — мусор на выходе» (garbage in, garbage out).
- Предварительная проверка данных: пропуски, выбросы, дубликаты, типы признаков.

### Тема 1. Постановка задачи регрессии

- Регрессия как задача обучения с учителем; непрерывная целевая переменная.
- Объекты, признаки, целевая переменная; матричное представление (`X`, `y`, веса `w`).
- Примеры задач регрессии (цена дома, температура, спрос); обзор проекта House Prices.

### Тема 2. Линейная регрессия и функции потерь

- Уравнение линейной регрессии; геометрический смысл.
- Функции потерь: MSE, MAE; их свойства и чувствительность к выбросам.
- Аналитическое решение (нормальное уравнение); условия применимости.

### Тема 3. Градиентный спуск

- Производная и градиент функции; направление наискорейшего убывания.
- Шаг обучения (learning rate), сходимость и расходимость; влияние масштаба признаков.
- Реализация градиентного спуска для линейной регрессии «с нуля»; правило обновления весов.
- Варианты: пакетный (batch), стохастический (SGD), мини-батч.

### Тема 4. Переобучение, недообучение и регуляризация

- Диагностика по кривым обучения (train vs validation); соотношение bias/variance.
- Регуляризация: L1 (Lasso), L2 (Ridge); влияние на веса.
- Подбор гиперпараметров: коэффициент регуляризации, learning rate, число итераций.
- Масштабирование признаков (`StandardScaler`) перед регуляризацией и градиентным спуском.

### Тема 5. Метрики качества регрессии и проект House Prices

- Метрики: MAE, RMSE, R²; что показывает каждая.
- Валидация модели: разделение train/test, кросс-валидация.
- Особенности проекта House Prices: целевая переменная (цена), лог-трансформация, отправка submission.

## Формат и оценивание
- Формат: проектное обучение через Kaggle-соревнования; работа в команде (3–4 человека).
- В модуле: публикация материала (теория + задание), вводная лекция и разбор задания.
- Консультации (3 в неделю, по желанию); обязательно показать прогресс команды минимум 2 раза до КТ.
- В конце модуля сдаётся итоговый Jupyter-ноутбук; все работы проверяются через антиплагиат.
- Контрольная точка (КТ): защита командой; вопросы по реализации к каждому члену команды.
- Итог за модуль = ноутбук (качество кода, понимание, макс. 50) + результат в Kaggle (порог по метрике, макс. 50).
- Итог за семестр — средняя арифметическая за 4 модуля.
