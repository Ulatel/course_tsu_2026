## Архитектурный контекст

Курс — 8 модулей на 2 семестра, формат проектного обучения через Kaggle-соревнования. См. README.md — программа, образовательные результаты, правила оценивания.

Каждый модуль — папка с комплектом материалов, связанных пайплайном: `N_План.md` → `N_Лекция.md` → `N_Лекция.pptx` → `N_Теория.md` (+ `N_Задание.ipynb`). План — источник истины по содержанию: раздел «Темы лекции» превращается в текст лекции, «Темы теории» — в конспект.

Генерация и правки автоматизированы скиллами в `.kilo/skills/`: `module-topics` (дополнить План темами), `lecture-writer` (текст лекции), `pptx-writer` (презентация), `theory-writer` (конспект), `lecture-sync` (инкрементная синхронизация md ↔ pptx).

## Конвенции

### Иерархия файлов

```
Модуль N. <Название>/
  N_План.md          — план модуля: результаты, темы лекции, темы теории, проект
  N_Лекция.md        — полный текст лекции («Часть N», метки [Слайд N])
  N_Лекция.pptx      — презентация; полный текст выступления — в notes
  N_Теория.md        — конспект для самостоятельного изучения («Блок N»)
  N_Задание.ipynb    — задание проекта (Kaggle)
```

### План (`N_План.md`)

- Секции: Образовательные результаты (Знают / Умеют / Понимают), Темы лекции, Темы теории (Тема 0..N), Проект (Kaggle), Материалы
- Изменение содержания модуля начинается с Плана, затем переносится в лекцию и теорию
- Результаты модуля согласованы с таблицами README.md

### Лекция (`N_Лекция.md`)

- Разговорный стиль, разделы `## Часть N. <Заголовок>`; эталон — `1_Лекция.md`
- Сквозные метки слайдов: `[Слайд N]`, `[Слайды N–M]`, `[иллюстрация]` — синхронизируют текст с pptx
- Финал лекции — «Спасибо за внимание»

### Теория (`N_Теория.md`)

- Блоки `# Блок N. <Заголовок>` с подразделами; эталон — `1_Теория.md`
- Python-сниппеты (pandas, sklearn, numpy, torch) в блоках ` ```python `
- Формулы — строчно (например, `x_scaled = (x - mean_x) / stddev_x`)
- `ВАЖНО!` — для подводных камней (data leakage, дисбаланс классов и т.п.)
- Номер следующего блока определяется по текущему содержимому файла, не хардкодится

### Презентации (`N_Лекция.pptx`)

- Фирменный стиль курса: 16:9, IBM Plex Sans, акцент #8E39E2
- Не править бинарно/вручную — генерация через `pptx-writer`, изменения через `lecture-sync`
- Если в презентации есть ручная работа (иллюстрации, правка слайдов) — полная пересборка запрещена

### Общее

- Язык — русский, без эмодзи
- Секреты (`.env`, `*.key`) не коммитить; перед коммитом проверять `git status`
- Ноутбуки заданий коммитятся с чистыми output ячеек (если output не нужен для проверки)

## Локальная верификация

Перед отправкой изменений:

1. Окружение: conda-окружение `course_ml` (Python 3.12), версии — `requirements.txt`; установка — `УСТАНОВКА_ОКРУЖЕНИЯ.md` или `install.ps1`
2. Если изменения затрагивают стек/ноутбуки: `python tests/smoke_test.py` — ожидается 9/9 PASS
3. Для сгенерированных/правленых md — проверить артефакты генерации:
   - CJK-вставки: `grep -n "[\x{4e00}-\x{9fff}]" <file> -P`
   - целостность структуры: «Спасибо за внимание» в конце лекции, непрерывная нумерация «Блок N» / «Часть N» / `[Слайд N]`
4. Для pptx после синхронизации: открыть презентацию, сверить число слайдов с метками `[Слайд N]` в md и наличие текста выступления в notes
