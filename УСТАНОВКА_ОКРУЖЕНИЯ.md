# Установка окружения для курса «Практикум по машинному обучению и нейронным сетям»

Инструкция по развёртыванию рабочего места: от базового софта до проверки установки.

---

## 1. VS Code

**Скачать:** https://code.visualstudio.com/download (Windows — User Installer, x64)

### Необходимые расширения

| Расширение       | ID                                  | Зачем                                                                                           |
| -------------------------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Python                     | `ms-python.python`                | Язык, отладка, запуск скриптов                                              |
| Pylance                    | `ms-python.vscode-pylance`        | Автодополнение, типы                                                               |
| Jupyter                    | `ms-toolsai.jupyter`              | Работа с ноутбуками (.ipynb) — основной формат работ курса |
| Python Environment Manager | `ms-python.vscode-python-manager` | Выбор окружения course_ml                                                              |
| Ruff                       | `charliermarsh.ruff`              | Линтер/форматтер Python                                                               |
| Excel Viewer               | `GrapeCity.gc-excelviewer`        | Просмотр CSV (датасеты Kaggle)                                                       |

Установка из терминала:

```powershell
code --install-extension ms-python.python `
     --install-extension ms-python.vscode-pylance `
     --install-extension ms-toolsai.jupyter `
     --install-extension ms-python.vscode-python-manager `
     --install-extension charliermarsh.ruff `
     --install-extension GrapeCity.gc-excelviewer
```

Минимально достаточный набор: **Python + Pylance + Jupyter**.

После установки: открыть папку курса → `Ctrl+Shift+P` → *Python: Select Interpreter* → указать `D:\envs\course_ml\python.exe` (или свой путь к окружению).

## 4. Python 3.12 + pip

Python входит в conda-окружение — отдельно ставить не нужно.

Создание окружения курса:

```powershell
conda create -n course_ml python=3.12 -y
conda activate course_ml
python --version    # Python 3.12.x
pip --version
```

> **Важно (Windows):** если системный диск забит, размещайте окружение на другом диске:
> `conda create -p D:\envs\course_ml python=3.12 -y`
> При установке больших пакетов (torch) направляйте кэш и temp на тот же диск:
> `$env:TMP="D:\tmp"; $env:TEMP="D:\tmp"` и `pip install --cache-dir D:\pip_cache ...`

## 5. Зависимости курса

Основной способ — `requirements.txt` из корня репозитория (версии зафиксированы по проверенному окружению):

```powershell
conda activate course_ml
pip install -r requirements.txt
```

Состав (подробно — в самом requirements.txt):

- **Классический ML (М1–М2):** numpy, pandas, scipy, matplotlib, seaborn, statsmodels, scikit-learn, tqdm
- **Ансамбли, дисбаланс (М3):** xgboost, lightgbm, catboost, imbalanced-learn
- **Нейросети (М4–М8):** torch, torchvision, transformers, sentence-transformers
- **Компьютерное зрение (М5):** ultralytics (YOLO), opencv-python, Pillow, albumentations, pycocotools
- **Fine-tuning (М5, М8):** datasets, accelerate, peft
- **Разметка данных (М5):** label-studio
- **Ноутбуки:** jupyter

### Проверка установки

```powershell
python tests/smoke_test.py
```

Ожидаемый результат: `Пройдено: 9/9` — смоук-тесты всех модулей (Titanic/KNN, регрессия+градиентный спуск, ансамбли+SMOTE, перцептрон, PINN, YOLO+аугментации, pipeline, текстовые энкодеры, доп. стек).

## 6. Poetry (опционально)

**Документация:** https://python-poetry.org/

Альтернатива pip для управления зависимостями. Для курса достаточно pip + requirements.txt; poetry — если удобно вести собственные проекты с lock-файлом.

Установка (PowerShell):

```powershell
pip install poetry
# или изолированно:
(Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | python -
```

Инициализация в проекте:

```powershell
poetry init
poetry add numpy pandas scikit-learn
```

## 7. Дополнительно

### Kaggle CLI

Для участия в соревнованиях (М1–М8) и отправки сабмитов:

```powershell
pip install kaggle
```

API-токен: kaggle.com → Account → *Create New API Token* → положить `kaggle.json` в `C:\Users\<user>\.kaggle\`.

### Label Studio (М5)

Ставится из requirements.txt. Запуск (веб-интерфейс на http://localhost:8080):

```powershell
label-studio
```

### Hugging Face аккаунт (М5, М8)

Для скачивания моделей и датасетов: https://huggingface.co/ → Register.
Токен (для приватных моделей и снятия лимитов): `huggingface-cli login`.

### CUDA / GPU (опционально, М5)

По умолчанию torch ставится CPU-сборкой — достаточно для всех модулей, кроме разве что дообучения YOLO/UNet на больших датасетах. Для GPU:

1. Проверить NVIDIA-драйвер: `nvidia-smi`
2. Переустановить torch:

```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

Проверка: `python -c "import torch; print(torch.cuda.is_available())"`
