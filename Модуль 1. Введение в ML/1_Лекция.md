## **ЧАСТЬ II. ОСНОВНЫЕ ПОНЯТИЯ МАШИННОГО ОБУЧЕНИЯ**

### **5. Искусственный интеллект vs Машинное обучение**

#### **Artificial Intelligence (Искусственный интеллект)**

**Определение:** Система, способная принимать решения на основании состояния мира.

**Пример — Deep Blue (1996):**
Система IBM, обыгравшая Гарри Каспарова в шахматы. Deep Blue принимала решения, анализируя текущее состояние доски (положение фигур). Это классический пример AI, работающего на основе заданных правил и перебора вариантов.

> Ключевая фраза: **«на основании состояния мира»**

---

#### **Machine Learning (Машинное обучение)**

**Определение:** Система, принимающая решения на основании **накопленного опыта** и состояния мира.

**Визуализация разницы:**
Представьте три ситуации прогнозирования погоды:

1. «В хмурый день идёт дождь» → накопленный опыт + текущее состояние
2. «Сегодня тоже хмурное небо» → только состояние мира
3. «Будет дождь» → предсказание на основе опыта

ML объединяет оба источника информации!

**Примеры из жизни:**

| Контекст                            | Накопленный опыт                     | Состояние мира                                                       | Принятое решение                  |
| ------------------------------------------- | --------------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------ |
| Рекомендации видео         | История просмотров, лайки     | Текущий пользователь                                           | Показать конкретное видео |
| Голосовые ассистенты     | Записи голосов разных людей | Аудио «Привет! Как т...»                                         | Распознать фразу                  |
| Прогнозирование продаж | Данные о прошлых продажах     | Текущий состав товара, длительность горения | Предсказать спрос                |

**Медицинский пример:**
Медицинский центр хочет предсказывать вероятность развития диабета 2-го типа у пациента на основе его возраста, индекса массы тела, уровня глюкозы в крови, наследственности и образа жизни.

**Недвижимость:**
Агентство недвижимости хочет оценить рыночную стоимость квартиры на основе её характеристик (площадь, этаж, район, год постройки, материал стен).

---

### **6. Традиционное программирование vs Машинное обучение**

#### **Традиционное программирование:**

```
Данные → Программа → Ответ
```

**Примеры:**

- Вход: `2 и 2` → Программа: `сложить` → Выход: `4`
- Вход: `положение шахмат на поле` → Программа: `определить оптимальный ход` → Выход: `следующий ход`

Человек **заранее прописывает правила** (алгоритм).

---

#### **Машинное обучение:**

```
Ответ + Данные → Система → Правила
```

Система сама **выучивает правила** на основе примеров (данных и правильных ответов).

**Сравнение на примере сложения:**

| Подход             | Входные данные | Что задаётся           | Результат                                  |
| ------------------------ | --------------------------- | --------------------------------- | --------------------------------------------------- |
| Традиционное | `2 и 2`                  | Алгоритм сложения | `4`                                               |
| ML                       | `4` и `2 и 2`         | Система обучается | Выученное правило`сложить` |

---

### **7. Основные термины машинного обучения**

#### **Базовая схема:**

```
Признаки (Features X)     Целевая переменная (Target Y)
┌─────────────┐           ┌─────────────┐
│ Состояние   │           │ Был ли      │
│ неба        │           │ дождь       │
│ хмурое      │           │ Был         │
│ ясное       │           │ Не было     │
└─────────────┘           └─────────────┘
          ↓                         ↓
          └────────→ [МОДЕЛЬ] ←───────┘
                        ↓
              Предсказание:
          «В хмурый день идёт дождь»
```

**Обучение** — процесс выявления **истинной зависимости** моделью машинного обучения.

---

#### **Ключевые термины:**

**1. Обучающая выборка (Training Dataset)**
Накопленный опыт. Каждый объект в выборке представляет собой набор признаков (**features**) и соответствующее ему значение целевой переменной (**target**).

**2. Истинная зависимость**
Правила перевода признаков в целевую переменную (то, что мы хотим найти).

**3. Модель машинного обучения**
Алгоритм, выявляющий истинную зависимость на основе обучающей выборки.

**4. Обучение**
Процесс выявления истинной зависимости моделью машинного обучения.

**5. Объект / наблюдение (Object / Sample / Observation / Instance)**
Одна строка в данных (один пример).

---

### **8. Практический пример: Шахматы**

**Задача:** Научить модель предсказывать лучший ход в шахматах.

**Обучающая выборка:**

| Признаки (Features)           |                                                          | Целевая переменная (Target) |
| ------------------------------------- | -------------------------------------------------------- | -------------------------------------------- |
| **Состояние поля** | **Предыдущий ход соперника** | **Следующий ход**          |
| Пешка G2, ладья C3...       | ладья на C3                                       | Конь на F6                             |
| Слон B4, пешка G6...         | Король на D5                                     | Пешка на C5                           |
| ...                                   | ...                                                      | ...                                          |

**Процесс:**

1. Загружаем таблицу с тысячами партий → **Обучающая выборка**
2. Подаем данные в модель → **Модель ML выучивает зависимость** → **Истинная зависимость**
3. Для новой позиции модель выдаёт предсказание → **Следующий ход: Конь на F3**

### **9. Вопрос для размышления**

**В чём основная разница между Deep Blue и ML-моделью?**

| Deep Blue                                                                                       | ML-модель                                                                             |
| ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Алгоритм,**принимающий решение** на основе правил | Модель,**обученная на данных** находить правила |

Deep Blue — классический AI с жёстко заданными правилами.
ML-модель сама **выучила** эти правила из примеров партий.

## **ЧАСТЬ III. КОГДА ИСПОЛЬЗОВАТЬ МАШИННОЕ ОБУЧЕНИЕ?**

### **11. Когда НУЖНО ML?**

**Критерий 1:** Определять правила для решения задачи самостоятельно **сложно и долго**.

✅ **Хороший пример:**
Есть фотографии собак и кошек, необходимо определить, какое животное находится на фото.
→ Человек легко узнаёт, но **очень сложно формализовать правила** («если уши треугольные и усы длинные...»).

❌ **Плохой пример:**
Есть масса тела и ускорение свободного падения. Необходимо рассчитать силу тяжести.
→ Есть чёткая формула $F = mg$. ML здесь не нужен!

---

**Критерий 2:** Нужно учесть **множество факторов и условий**.

✅ **Пример:**
Есть разнообразные параметры автомобиля (марка, год, пробег, состояние, комплектация). Необходимо определить стоимость.
→ Факторов много, их влияние сложно описать вручную.

---

### **12. Когда МОЖНО использовать ML?**

**Главное условие: ЕСТЬ ДАННЫЕ.**

Основываясь на данных, модель выявляет истинную зависимость.
Если данных мало или они плохого качества, то и **истинная зависимость будет выявлена плохо**.

→ В таком случае качество предсказаний будет низким.

**Вывод:** ML возможен при наличии достаточного количества качественных данных.

### **14. Supervised Learning (Обучение с учителем)**

**Определение:** Правильные ответы для каждого объекта обучающей выборки **заранее известны**.

---

#### **14.1. Регрессия (Regression)**

**Математическая запись:** $Y = \mathbb{R}$ или $Y = \mathbb{R}^K$

Целевая переменная — **непрерывное число**.

**Примеры задач:**

- Предсказание продолжительности поездки на каршеринге
- Спрос на конкретный товар в конкретный день
- Погода в вашем городе на завтра

*Визуальный пример:* Экстраполяция линейной зависимости (график «моё желание» vs «количество дней»).

---

#### **14.2. Многоклассовая классификация (Multi-class Classification)**

**Математическая запись:** $Y = 1, ..., K$

Целевая переменная — **один из K классов**.

**Примеры задач:**

- Определение предметной области для научной статьи
- Классификация типов рака
- Классификация дорожных знаков для систем автономного вождения

---

#### **14.3. Бинарная классификация (Binary Classification)**

**Математическая запись:** $Y = 0, 1$

Целевая переменная — **один из двух классов** (да/нет).

**Примеры задач:**

- Кликнет ли пользователь по рекламному объявлению?
- Вернёт ли клиент кредит в установленный срок?
- Сдаст ли студент сессию?

---

#### **14.4. Multilabel Classification (Многометочная классификация)**

**Математическая запись:** $Y = \{0, 1\}^K$

Каждому объекту может быть присвоено **несколько меток одновременно**.

**Примеры задач:**

- Автоматическое проставление тегов для ресторанов (итальянская кухня + семейная атмосфера + ...)
- Проставление жанров музыки (рок + поп + электроника)

---

### **16. Unsupervised Learning (Обучение без учителя)**

**Определение:** Правильные ответы для каждого объекта обучающей выборки **заранее НЕ известны**.

---

#### **16.1. Кластеризация (Clustering)**

**Задача:** Группировка похожих объектов вместе.

**Примеры:**

- Классификация документов из электронной библиотеки по темам
- Кластеризация новостей по сюжетам
- Группировка ответов респондентов по содержанию

**Визуализация:**

```
До:                    После:
• • • •                ● ● ●
  • • •                      ● ● ●
    • • • •
```

Точки (объекты) группируются в кластеры (зелёные круги) на основе сходства.

---

### **17. Reinforcement Learning (Обучение с подкреплением)**

**Определение:** Алгоритм за каждое действие получает **награду или наказание**.

**Пример — AlphaGo (Google DeepMind, 2016):**
Система, обыгравшая чемпиона мира по Го Ли Седоля. AlphaGo обучалась, играя миллионы партий сама с собой и получая награду за победу.

**Механика:**

- Агент совершает действие в окружающей среде
- Средда возвращает награду (positive reward) или наказание (negative reward)
- Агент учится выбирать действия, максимизирующие суммарную награду

**Другие применения:**

- Робот-пылесос, изучающий планировку квартиры
- Автономные автомобили
- Управление дроном

- Определяет объекты: P 0.6 sheep, P 0.3 dog, P 0.1 cat, P 0.0 horse

### **20. Этапы работы над ML-проектом**

1. **Определение проблемы (Problem Definition)** — что мы хотим предсказать?
2. **Сбор данных (Data Gathering)** — откуда берём данные?
3. **Подготовка данных (Data Preparation / Wrangling)** — очистка, обработка пропусков
4. **Исследовательский анализ (Exploratory Analysis)** — понимание данных, визуализации
5. **Инженерия признаков (Feature Engineering)** — создание новых признаков
6. **Обучение моделей** — выбор и тренировка алгоритмов
7. **Валидация и внедрение (Validation & Implementation)** — проверка качества, deploy
8. **Оптимизация и стратегирование (Optimization & Strategize)** — улучшение результатов
