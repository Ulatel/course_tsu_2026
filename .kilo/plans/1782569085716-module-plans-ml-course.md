# План: папки и План.md для 8 модулей курса «Практикум по машинному обучению и нейронным сетям»

## Контекст
Источник содержания — презентация `Практикум по машинному обучению и нейронным сетям.pptx` (8 слайдов):
- Слайд 2: образовательные результаты 1 семестра (модули 1–4): знают / умеют / понимают.
- Слайд 3: образовательные результаты 2 семестра (модули 5–8): знают / умеют / понимают.
- Слайд 4: общий формат и оценивание модуля (общий для всех модулей).
- Слайд 5: программа 1 семестра — названия модулей 1–4, краткие результаты, проект (Kaggle), материалы.
- Слайд 6: программа 2 семестра — названия модулей 5–8, краткие результаты, проект (Kaggle), материалы.

Текущая структура репозитория:
```
1 семестр/  → Задание.ipynb, Лекция.pptx, Теория.md   (это материалы Модуля 1)
2 семестр/  → План.md (пустой)
```

## Принятые решения
1. **Структура:** 8 папок модулей **плоско в корне** репозитория.
2. **Существующие файлы:** перенести `Теория.md`, `Лекция.pptx`, `Задание.ipynb` из `1 семестр/` в `Модуль 1. Введение в ML/`; **удалить** папки `1 семестр/` и `2 семестр/` (включая пустой `2 семестр/План.md`).
3. **Шаблон План.md:** полный — Заголовок + семестр → Образовательные результаты (Знают / Умеют / Понимают) → Проект (Kaggle) → Материалы → Формат и оценивание.

## Порядок задач
1. Создать 8 папок модулей (список выше).
2. Перенести `Теория.md`, `Лекция.pptx`, `Задание.ipynb` из `1 семестр/` в `Модуль 1. Введение в ML/`.
3. Удалить папки `1 семестр/` и `2 семестр/` (со всем содержимым).
4. Записать `План.md` в каждую из 8 папок по шаблону ниже и содержанию из раздела «Содержание по модулям».
5. Проверка: в корне 8 папок `Модуль N…`, в каждой есть `План.md`; папок-семестров нет; файлы Модуля 1 на месте.

## Шаблон План.md (повторять для каждого модуля)
```
# Модуль N. <Название>

**Семестр:** <1 | 2>

## Образовательные результаты

### Знают
- …

### Умеют
- …

### Понимают
- …

## Проект (Kaggle)
<описание соревнования / задачи>

## Материалы
- Лекция: …
- Статья / ноутбук: …

## Формат и оценивание
- Формат: проектное обучение через Kaggle-соревнования; работа в команде (3–4 человека).
- В модуле: публикация материала (теория + задание), вводная лекция и разбор задания.
- Консультации (3 в неделю, по желанию); обязательно показать прогресс команды минимум 2 раза до КТ.
- В конце модуля сдаётся итоговый Jupyter-ноутбук; все работы проверяются через антиплагиат.
- Контрольная точка (КТ): защита командой; вопросы по реализации к каждому члену команды.
- Итог за модуль = ноутбук (качество кода, понимание, макс. 50) + результат в Kaggle (порог по метрике, макс. 50).
- Итог за семестр — средняя арифметическая за 4 модуля.
```
Блок «Формат и оценивание» общий для всех модулей (источник — слайд 4).

## Содержание по модулям

### Модуль 1. Введение в ML — Семестр 1
- **Знают:** базовую терминологию ML; типы задач ML (классификация, регрессия и др.); общий процесс (pipeline) обучения модели — постановка задачи, подготовка данных, выбор и обучение модели, применение.
- **Умеют:** проводить разведочный анализ данных (EDA); выполнять первичную обработку и feature engineering; обучать простую модель для классификации; оценивать модель стандартными метриками.
- **Понимают:** общий процесс обучения модели (постановка задачи, подготовка данных, обучение, применение).
- **Проект (Kaggle):** задача классификации — Titanic (выжил / не выжил).
- **Материалы:** лекция «Что такое ML, какие бывают задачи, общий процесс обучения модели»; шаблон Jupyter-ноутбука с разбором синтаксиса и шаблоном пайплайна обучения.
- **Примечание:** сюда переносятся существующие `Теория.md`, `Лекция.pptx`, `Задание.ipynb`.

### Модуль 2. Регрессия и градиентный спуск — Семестр 1
- **Знают:** основные показатели качества данных (точность, полнота, согласованность, своевременность); принцип работы и постановку задачи регрессии; понятия гиперпараметров и переобучения/недообучения.
- **Умеют:** строить и валидировать регрессионные модели; реализовывать градиентный спуск для линейной регрессии «с нуля»; подбирать гиперпараметры; интерпретировать результаты обучения.
- **Понимают:** оптимизацию функции потерь через градиентный спуск.
- **Проект (Kaggle):** прогнозирование стоимости домов.
- **Материалы:** лекция «Постановка задачи регрессии, процесс обучения, минимизация ошибки через градиентный спуск»; теоретический текст «Как работает градиентный спуск, обучение регрессии».

### Модуль 3. Ансамбль. Задача классификации — Семестр 1
- **Знают:** принципы построения ансамблевых моделей (бэггинг, бустинг); особенности применения ML для задач в предметной области (физика).
- **Умеют:** применять алгоритмы ML к задачам классификации в физике; использовать популярные ансамбли (XGBoost, Random Forest); обучать модели на несбалансированных данных.
- **Понимают:** как работает бустинг.
- **Проект (Kaggle):** прогнозирование Бозона Хиггса или поиск редких частиц.
- **Материалы:** лекция «Принцип работы ансамблей, виды ансамблей»; статья «Как работает бустинг»; шаблон Jupyter-ноутбука с пояснениями по предобработке данных.

### Модуль 4. Введение в нейросети — Семестр 1
- **Знают:** что такое нейронные сети и многослойный перцептрон; базовые принципы работы нейросетей (функция активации, прямой проход); ключевые задачи, решаемые нейросетями.
- **Умеют:** применять простейшие модели нейросетей; работать с PyTorch; реализовывать архитектуру перцептрона; использовать нейросеть для классификации изображений (MNIST) или регрессии.
- **Понимают:** как работает простейший перцептрон.
- **Проект (Kaggle):** классифицировать цифры (MNIST) либо — на основе геофизических параметров на заданной глубине — предсказать вероятность отклонения бурового долота от нормы.
- **Материалы:** лекция «Введение в нейросети, решаемые задачи, обучение нейросетей»; ноутбук с разбором синтаксиса PyTorch; статья «Архитектура многослойного перцептрона».

### Модуль 5. Physics-Informed Neural Networks (PINNs) — Семестр 2
- **Знают:** архитектуру нейронной сети на основе её текстового описания.
- **Умеют:** модифицировать расчёт функции потерь для учёта соответствия предсказаний законам физики; применять PINN для прикладных инженерных или научных задач.
- **Понимают:** как рассчитывается функция потерь (loss) в нейросетях.
- **Проект (Kaggle):** прогнозирование оставшегося времени заряда литий-ионной батареи.
- **Материалы:** лекция «Подробнее про обучение нейросетей, как считается loss, как его модифицировать»; статья про PINN.

### Модуль 6. Работа с крупными моделями — Семестр 2
- **Знают:** основы аугментации данных.
- **Умеют:** размечать данные для задач компьютерного зрения; дообучать готовые сложные архитектуры (например, YOLO) под конкретную задачу; применять методы аугментации данных.
- **Понимают:** принципы дообучения (fine-tuning) масштабных предобученных моделей.
- **Проект (Kaggle):** дообучить YOLO + обучить свою нейросеть (например, UNet).
- **Материалы:** лекция «Принципы дообучения моделей»; материал по архитектуре UNet.

### Модуль 7. Свободное решение задачи нейросетями или классическим ML — Семестр 2
- **Знают:** критерии выбора семейства моделей под задачу; подбор оптимальной метрики для оценки своей задачи.
- **Умеют:** самостоятельно ставить задачу ML в рамках предметной области; определять подходящее семейство моделей (нейросети или классический ML); полностью реализовывать pipeline — от данных до выбора, обучения и применения модели.
- **Понимают:** как подойти к решению задачи в своей области.
- **Проект (Kaggle):** классификация типов облаков; либо детекция брака на конвейере; либо проект в предметной области студентов.
- **Материалы:** в презентации не указаны — оставить раздел с пометкой «Материалы будут добавлены».

### Модуль 8. Сложные архитектуры нейронных сетей — Семестр 2
- **Знают:** назначение и области применения современных архитектур: Transformer, GAN, GNN, Autoencoders.
- **Умеют:** применять готовые реализации сложных архитектур для нетривиальных задач (кластеризация текстов, классификация с помощью энкодеров и т. д.).
- **Понимают:** в презентации отдельно не выделено — раздел оставить пустым/с пометкой.
- **Проект (Kaggle):** кластеризация текстов с помощью обученных энкодеров для LLM; либо классификация текстов с разметкой или оценкой с помощью LLM; либо ещё один проект в предметной области студентов.
- **Материалы:** лекция про передовые архитектуры моделей.
