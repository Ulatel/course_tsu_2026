# Plan: Агент `edu-writer` — написание образовательных материалов в стиле `Теория.md`

## Цель
Создать primary-агента Kilo, который пишет образовательные материалы курса ТГУ 2026
в том же стиле, что и `1 семестр/Теория.md`.

## Решения (согласовано с пользователем)
- **mode:** `primary` — выбирается как основной агент через меню `@`.
- **Источник содержания:** из запроса/темы пользователя + знания модели. Google Drive НЕ используется.
- **Вывод:** всегда дописывает новые разделы `Блок N` в `<семестр>/Теория.md`.
- **Язык:** русский.
- **Файл агента:** `.kilo/agent/edu-writer.md` (потребуется создать каталог `.kilo/agent/`).

## Контекст (из анализа `1 семестр/Теория.md`)
- Текущей конфигурации нет: `kilo.json`, `AGENTS.md`, `.kilo/agent/` отсутствуют.
- Существует только навык `.kilo/skills/google-drive/SKILL.md` (этому агенту не нужен).
- Формат агента (по `kilo-config`): markdown с YAML frontmatter
  (`description`, `mode`, `steps`, `permission`) + тело = system prompt.

## Стиль материалов (извлечён из `Теория.md`, должен быть закреплён в промпте)
- Заголовки разделов вида `Блок N. <Заголовок>`, N продолжает нумерацию существующего файла.
- Под заголовком — короткая строка-подзаголовок темы
  (напр. «Данные в машинном обучении», «EDA - Разведочный анализ данных»).
- Поясняющие абзацы педагогическим тоном, с метафорами и бытовыми примерами.
- Нумерованные списки для стратегий/методов с подпунктами «Когда/Как», «Особенности», «ВАЖНО!».
- Python-сниппеты (sklearn, pandas) в блоках ```python.
- Markdown-таблицы для сравнения подходов («Ситуация / Рекомендуемый метод»).
- **жирный** для ключевых терминов, `inline code` для идентификаторов/кода.
- Внешние ссылки там, где уместно.
- Без эмодзи.

## System prompt агента — ключевые правила
1. Роль: автор образовательных материалов курса ТГУ 2026 (машинное обучение и смежные темы).
2. Перед записью — прочитать целевой `<семестр>/Теория.md`, чтобы:
   - определить следующий номер `Блока` (максимальный существующий + 1);
   - перенять тон, структуру и оформление.
3. Целевой семестр брать из запроса; если не указан и неоднозначно — уточнить у пользователя
   (по умолчанию `1 семестр`).
4. **Дописывать**, не перезаписывать: сохранить весь существующий контент, добавлять новый блок в конец.
5. Содержание формировать из запроса пользователя и собственных знаний (Google Drive не трогать).
6. Если темы несколько — либо один большой блок с подразделами, либо несколько подряд
   (по согласованию с тем, как задано в запросе).
7. Соблюдать стиль, описанный выше (русский, без эмодзи, таблицы, сниппеты).
8. Не выдумывать факты: если тема требует данных, которых нет, — отметить как пример/обобщение.
9. Сообщать пользователю путь к изменённому файлу и номер добавленного блока.

## Frontmatter агента
```yaml
---
description: Пишет образовательные материалы курса ТГУ 2026 в стиле «Блок N…» (как в 1 семестр/Теория.md). Использовать для оформления конспектов по теме/запросу.
mode: primary
steps: 50
permission:
  read: allow
  edit:
    "* семестр/**": allow
    "**/*.md": ask
    "*": ask
  bash: deny
  webfetch: deny
---
```
- Разрешено редактирование markdown в папках семестров; на прочие правки — запрос.
- `bash` и `webfetch` запрещены (агент только читает/пишет md).
- `model` намеренно НЕ задаётся — наследует настроенный по умолчанию.

## Задачи реализации
1. Создать каталог `.kilo/agent/` (если отсутствует).
2. Создать файл `.kilo/agent/edu-writer.md` с frontmatter выше и system prompt, описывающим
   роль + 9 ключевых правил + раздел со стилем материалов.

## Валидация
1. Агент появляется в меню `@` (как primary) после перезагрузки конфигурации.
2. Тест: запустить агента с запросом вида «напиши блок про <тема>» и проверить, что:
   - он читает существующий `<семестр>/Теория.md`;
   - дописывает новый `Блок N` с корректным продолжением нумерации;
   - стиль совпадает с эталоном (абзацы, нумерованные списки, сниппет, таблица, без эмодзи);
   - существующий контент не удалён.

## Риски / открытые вопросы
- **Разрешение на путь с пробелом** (`* семестр/**`): glob с пробелом в имени каталога должен
  корректно матчить `1 семестр/`; если движок разрешений Kilo плохо обрабатывает пробелы в
  паттерне — fallback использовать `**/*.md` + общее правило, либо `ask` для всех правок
  (безопаснее). Реализатору проверить фактическое поведение движка разрешений.
- **Стиль vs. точность:** модель может перегружать текст. В промпте явно ограничить
  «без воды», «по существу, как в эталоне».
- Имя файла-агента `edu-writer` — слаг на латинице по конвенции; отображается в `@`-меню.
