# AGENTS.md

Курс ТГУ 2026 «Практикум по машинному обучению и нейронным сетям» — 8 модулей, проектное обучение через Kaggle. Markdown + Python-ноутбуки + pptx, генерация через скиллы в `.kilo/skills/`.

Описание и конвенции → README.md, CONTRIBUTING.md

## Boundaries

### ALWAYS
- Следовать пайплайну модуля: `N_План.md` → `N_Лекция.md` → `N_Лекция.pptx` → `N_Теория.md`; источник истины по содержанию — План
- Для генерации/правки материалов использовать профильные скиллы: `module-topics`, `lecture-writer`, `pptx-writer`, `theory-writer`, `lecture-sync`
- Изменение содержания модуля начинать с `N_План.md` (разделы «Темы лекции» / «Темы теории»), затем переносить в лекцию/теорию
- Писать по-русски, без эмодзи; стиль — по эталонам `1_Лекция.md` и `1_Теория.md`
- После изменений, затрагивающих стек/ноутбуки, запускать `python tests/smoke_test.py` (ожидается 9/9 PASS)

### ASK FIRST
- Переименование папок модулей и файлов `N_*.md/pptx` (ломает ссылки в README, скиллах, планах)
- Полная пересборка `N_Лекция.pptx`, в которой есть ручная работа (иллюстрации, правка слайдов) — вместо неё использовать `lecture-sync`
- Изменение нумерации/порядка модулей и структуры курса
- Правка зафиксированных версий в `requirements.txt`

### NEVER
- Не коммитить секреты (`.env`, `*.key`) — они в `.gitignore`, но проверяй перед коммитом
- Не править `.pptx` вручную/бинарно — только через скиллы (`pptx-writer` / `lecture-sync`)
- Не трогать файлы `~$*.pptx` — это блокировочные файлы Office (презентация открыта)
- Не хардкодить номера «Блок N» в теории и «Часть N» в лекции — нумерация вычисляется по текущему содержимому файла
- Не переписывать эталонные файлы 1-го модуля — они задают стиль всего курса

## Структура проекта

- `README.md` — программа курса: образовательные результаты по семестрам, формат, правила
- `Модуль N. <Название>/` — комплект материалов модуля:
  - `N_План.md` — план: результаты (знают/умеют/понимают), «Темы лекции», «Темы теории», проект Kaggle, материалы
  - `N_Лекция.md` — полный текст лекции: разделы «Часть N», метки `[Слайд N]`, `[Слайды N–M]`, `[иллюстрация]`
  - `N_Лекция.pptx` — презентация в фирменном стиле (16:9, IBM Plex Sans, акцент #8E39E2); полный текст выступления — в notes
  - `N_Теория.md` — конспект для самостоятельного изучения: блоки `Блок N` с подразделами
  - `N_Задание.ipynb` — задание проекта
- `.kilo/skills/` — скиллы пайплайна: `module-topics`, `lecture-writer`, `pptx-writer` (generate_pptx.py), `theory-writer`, `lecture-sync` (sync_lecture.py)
- `.kilo/agent/edu-writer.md` — агент оформления конспектов
- `tests/smoke_test.py` — смоук-тесты стека всех модулей (М1–М8 + доп)
- `requirements.txt` — версии по проверенному окружению course_ml (Python 3.12)
- `install.ps1`, `УСТАНОВКА_ОКРУЖЕНИЯ.md` — развёртывание рабочего места
- `todo` — накопленные задачи по курсу
- `examples/` — эталоны AGENTS/CONTRIBUTING из другого проекта (не часть курса)

## Key Domain Concepts

**Модуль** — папка `Модуль N. <Название>`, 8 штук на 2 семестра. Единица курса: план, лекция, презентация, теория, задание.

**План** (`N_План.md`) — источник истины по содержанию модуля. Раздел «Темы лекции» превращается в текст лекции, «Темы теории» (Тема 0..N) — в конспект.

**Лекция** (`N_Лекция.md`) — текст выступления, разговорный стиль. Слайд-маркеры `[Слайд N]` синхронизируют текст с презентацией; `[иллюстрация]` — слайды-картинки. Финал — «Спасибо за внимание».

**Теория** (`N_Теория.md`) — конспект для самостоятельного изучения: блоки `Блок N`, Python-сниппеты, формулы строчно, `ВАЖНО!` для подводных камней.

**Смоук-тест** — `tests/smoke_test.py`: на каждый модуль — тест его стека (EDA+KNN, регрессия+GD, ансамбли, PyTorch, PINN, YOLO+CV, pipeline, энкодеры). Индикатор здоровья окружения.

**Синхронизация** (`lecture-sync`) — инкрементный перенос правок между `N_Лекция.md` и `N_Лекция.pptx` с сохранением ручной работы; в отличие от полной пересборки `pptx-writer`-ом.

## Грабли пайплайна генерации

- Полная пересборка pptx стирает ручную работу (иллюстрации, правку слайдов): для живых презентаций — только `lecture-sync`, `pptx-writer` — для новых/переписываемых модулей.
- Метки `[Слайд N]` в лекции и реальное число слайдов в pptx расходятся после ручных правок — после синхронизации сверяй нумерацию.
- После генерации md-файлов проверяй артефакты: CJK-вставки, потерянные «Спасибо за внимание» в конце лекции, дыры в нумерации блоков.
- Агент edu-writer дописывает блоки только в конец `Теория.md` — не поручай ему вставки в середину; нумерацию блоков он определяет сам по файлу.
- Ноутбуки заданий открываются в Jupyter: перед коммитом чисти output ячеек, если они не нужны для проверки.
