# Модуль 8. Сложные архитектуры нейронных сетей

**Семестр:** 2

## Образовательные результаты

### Знают

- назначение и области применения современных архитектур: Transformer, GAN, GNN, Autoencoders.

### Умеют

- применять готовые реализации сложных архитектур для нетривиальных задач (кластеризация текстов, классификация с помощью энкодеров и т. д.).

### Понимают

- когда какая архитектура уместна под задачу.

## Проект (Kaggle)

Кластеризация текстов с помощью обученных энкодеров для LLM; либо классификация текстов с разметкой или оценкой с помощью LLM; либо ещё один проект в предметной области студентов.
