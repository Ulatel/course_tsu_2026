## Формат

**Формат курса: проектное обучение через Kaggle-соревнования**

Курс разбит на 8 модулей. В каждом модуле:

- Публикация материала: теоретическая часть и задание.
- Вводная лекция по теории + разбор задания.
- Работа в команде (3-4 человека) над реализацией проекта — соревнования на Kaggle.
- Посещение консультаций (3 в неделю, по желанию) для помощи. Обязательно показать прогресс команды минимум 2 раза до КТ.
- Отправка итогового Jupyter notebook в конце модуля. Все работы проверяются через антиплагиат.

**Контрольная точка:**

- Проходит командой.
- Команда рассказывает о своей реализации, вопросы от принимающего по реализации к каждому члену команды.

**Итоговая оценка за модуль = сумма баллов за:**

- Баллы за сдачу ноутбука (качество кода, понимание) (максимум 50 баллов).
- Баллы за результат в соревновании Kaggle (достижение порога по метрике) (максимум 50 баллов).

**Итоговая оценка за семестр** — средняя арифметическая оценок за все 4 модуля.

- Распределения вероятностей (нормальное, биномиальное, Стьюдента и т. д.)

- Корреляция

**Программирование:**
